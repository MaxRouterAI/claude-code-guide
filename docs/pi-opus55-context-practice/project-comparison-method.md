## 计量与账单

- 输入、输出和缓存来自真实逐次回包与消费记录；没有按字数或本地分词器估算。
- 不把每次流中的累计usage重复加和；输出thinking是输出的一部分，不另加。
- API返回与账单有两种输入口径：有的已含缓存，有的是普通输入。逐条结合账单明确记录的格式与缓存细分归一，不能机械地对所有input字段再加一次缓存。
- 总输入=普通输入+缓存读+缓存写。表中的缓存列是输入细分，不重复相加。原始private回包完整保留，公开数据只放脱敏计量。
- 每笔请求ID对应消费记录，核对输出/缓存/归一输入；实际费用逐笔累加后，核对专用Key总额及底层quota。
- Pi修正结束时一次只读SSH核账暂时失败，费用当时标未知；随后只读复核成功，未新增生成请求，核实为$0.117078。
- 实际优惠不完全相同。例：CC成功任务前4笔享半价，第5笔标准价。表格直接使用实际扣费，不用理论价格替代，也不把所有价差说成Token优化。
